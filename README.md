# 🚀 CloudDrop - ფაილების ატვირთვა და გაზიარება

თანამედროვე, სრულფასოვანი და უსაფრთხო პლატფორმა ნებისმიერი ტიპის ფაილის ასატვირთად, შესანახად და უნიკალური ბმულით გასაზიარებლად.

---

## ✨ ძირითადი ფუნქციები

- **🎨 თანამედროვე მუქი დიზაინი (Dark Mode):** ლურჯი და იისფერი ნეონის ეფექტებით, Glassmorphism სტილითა და სრული რესპონსიულობით (კომპიუტერზე, პლანშეტსა და ტელეფონზე).
- **📂 ნებისმიერი ფორმატის მხარდაჭერა:** ფოტოები, ვიდეოები, მუსიკა, PDF დოკუმენტები, საოფისე ფაილები, ZIP/RAR არქივები, პროგრამები და სხვა.
- **⚡ Drag & Drop და პროგრესის ჩვენება:** ფაილის გადათრევა ან ღილაკით არჩევა, ატვირთვის პროგრესი რეალურ დროში (0-100%), ატვირთვის სიჩქარე (MB/s) და გაუქმების (Cancel) ღილაკი.
- **🔗 უნიკალური გაზიარების ბმული და QR კოდი:** თითოეულ ფაილზე გენერირდება უნიკალური ბმული ერთი დაწკაპუნებით კოპირებისთვის და მობილური QR კოდი ტელეფონის კამერით დასასკანერებლად.
- **📥 რეალური ჩამოტვირთვა ანგარიშის გარეშე:** საჯაროდ გაზიარებული ფაილის ჩამოტვირთვა შეუძლია ნებისმიერ მომხმარებელს რეგისტრაციის გარეშე, თავდაპირველი სახელითა და ფორმატით.
- **📊 ჩემი ფაილები (Dashboard):** ატვირთული ფაილების სია, ძებნა სახელით, გაფილტვრა კატეგორიებით (სურათები, ვიდეო, აუდიო, დოკუმენტები, არქივები), დალაგება, წაშლა და ჩამოტვირთვების მრიცხველი.
- **🛡️ უსაფრთხოება და რეალური საცავი:** ფაილები ინახება სერვერზე დაცულად (არა მხოლოდ localStorage-ში), უსაფრთხო `Content-Disposition` სათაურებითა და სტრიმინგით.
- **☁️ საცავის ორმაგი მოდელი (Dual-Storage):** მუშაობს როგორც ლოკალური დისკის საცავით (არ საჭიროებს გარე კონფიგურაციას), ასევე **Supabase Storage** Cloud საცავთან სრული ინტეგრაციით.

## 🛠️ ტექნოლოგიური სტეკი

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide React Icons, Canvas-Confetti, QRCode.react.
- **Backend:** Node.js, Express, Multer, Crypto/UUID, CORS, Dotenv.
- **Database & Persistence:** ტრანზაქციული ACID JSON საცავი + ინტეგრაცია Supabase Cloud Storage-თან.

## 🚀 ლოკალურად გაშვების ინსტრუქცია

### წინაპირობა:
- კომპიუტერზე დაინსტალირებული Node.js (v18+) და npm.

### 1. დამოკიდებულებების ინსტალაცია:
პროექტის მთავარ საქაღალდეში გახსენით ტერმინალი და შეასრულეთ:
```bash
# სერვერის პაკეტების დაყენება
npm --prefix server install

# კლიენტის პაკეტების დაყენება
npm --prefix client install
```

### 2. Frontend-ის აწყობა (Build):
```bash
npm run build
```

### 3. სერვერის გაშვება:
```bash
npm start
```
სერვერი გაეშვება მისამართზე: **`http://localhost:5000`**
გახსენით ეს მისამართი თქვენს ბრაუზერში.

## 🧑‍💻 დეველოპმენტის რეჟიმი (Hot Reload)

თუ გსურთ კოდის რედაქტირება და ცვლილებების მყისიერად დანახვა:
- **სერვერის გაშვება:**
  ```bash
  npm run server:dev
  ```
- **კლიენტის გაშვება ცალკე ფანჯარაში:**
  ```bash

  ```
  (Vite გაეშვება `http://localhost:5173`-ზე და ავტომატურად გადაამისამართებს API მოთხოვნებს 5000 პორტზე).

## ☁️ Supabase Cloud Storage-ის დაკავშირება (სურვილისამებრ)

თუ გსურთ ფაილების შენახვა უფასო ობიექტურ ღრუბლოვან საცავში (Supabase):

1. დარეგისტრირდით [Supabase.com](https://supabase.com)-ზე და შექმენით ახალი პროექტი.
2. მარცხენა მენიუში გადადით **Storage** -> **New Bucket**.
3. დაარქვით სახელი: `files` და აუცილებლად მონიშნეთ **Public bucket**.
4. გადადით **Project Settings** -> **API** და დააკოპირეთ:
   - **Project URL**
   - **anon / public key** ან **service_role key**
5. გახსენით ფაილი `server/.env` და ჩაწერეთ მონაცემები:
   ```env
   PORT=5000
   MAX_FILE_SIZE_MB=500
   STORAGE_TYPE=supabase
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_KEY=your-supabase-key
   SUPABASE_BUCKET=files
   ```
6. გადატვირთეთ სერვერი (`npm start`). ახლა ყველა ატვირთული ფაილი ავტომატურად შეინახება Supabase Cloud-ში!

## 🌐 საიტის ინტერნეტში გამოქვეყნება (Hosting)

ვინაიდან საიტს სჭირდება რეალური Backend და ფაილების საცავი:

### ვარიანტი A: Render.com (უფასო და მარტივი)
1. ატვირთეთ პროექტი თქვენს GitHub რეპოზიტორიაში.
2. შედით [Render.com](https://render.com)-ზე და დააჭირეთ **New +** -> **Web Service**.
3. მიაბით თქვენი GitHub რეპოზიტორია.
4. პარამეტრებში მიუთითეთ:
   - **Runtime:** Node
   - **Build Command:** `npm --prefix server install && npm --prefix client install && npm run build`
   - **Start Command:** `npm start`
5. **Environment Variables**-ში დაამატეთ:
   - `PORT=5000`
   - `MAX_FILE_SIZE_MB=500`
   - (თუ Supabase-ს იყენებთ) `STORAGE_TYPE=supabase`, `SUPABASE_URL`, `SUPABASE_KEY`, `SUPABASE_BUCKET`.
6. დააჭირეთ **Create Web Service**. საიტი რამდენიმე წუთში იქნება ონლაინ უფასო HTTPS დომენით!

### ვარიანტი B: Railway.app
1. შედით [Railway.app](https://railway.app)-ზე.
2. აირჩიეთ **Deploy from GitHub repo**.
3. Railway ავტომატურად ამოიცნობს Node.js პროექტს, ააწყობს და გაუშვებს.

## 🔒 უსაფრთხოება
- ფაილების სახელების სანიტარიზაცია და უნიკალური ID-ების გენერირება.
- `Content-Disposition` RFC 5987 სტანდარტი ქართული და საერთაშორისო სიმბოლოების სწორი კოდირებისთვის.
- ზომის ლიმიტის შემოწმება როგორც Frontend-ზე, ასევე Multer Middleware-ის დონეზე.
- `nosniff` და უსაფრთხო Content-Type სტრიმინგი მავნე სკრიპტების ავტომატური შესრულების თავიდან ასაცილებლად.
